# Code of Conduct — Fidel Assistant

## Notre engagement

Dans l’intérêt d’un environnement ouvert et accueillant, nous nous engageons, en tant que contributeurs et mainteneurs, à faire de la participation à ce projet une expérience sans harcèlement pour tout le monde, quels que soient l’âge, la taille corporelle, le handicap visible ou invisible, l’ethnicité, les caractéristiques sexuelles, l’identité ou l’expression de genre, le niveau d’expérience, l’éducation, le statut socio-économique, la nationalité, l’apparence personnelle, la race, la religion, ou l’orientation sexuelle.

## Comportements attendus

- Faire preuve d’empathie et de bienveillance
- Respecter les opinions et expériences différentes
- Accepter les retours constructifs
- Se concentrer sur ce qui est le mieux pour la communauté et les patients accompagnés
- Faire preuve de responsabilité face à ses erreurs

## Comportements inacceptables

- Langage ou images sexualisés, attention ou avances sexuelles non désirées
- Trolling, insultes, commentaires désobligeants, attaques personnelles ou politiques
- Harcèlement public ou privé
- Publication d’informations privées d’autrui (adresses physiques ou électroniques, données de santé) sans permission explicite
- Toute autre conduite jugée inappropriée dans un cadre professionnel

## Données de santé

Ce projet traite de données de santé sensibles. Il est **interdit** de partager, dans les issues, PR, logs ou captures d’écran, des données réelles de patients. Utiliser uniquement des données fictives ou anonymisées.

## Application

Les mainteneurs peuvent retirer, éditer ou rejeter des commentaires, commits, code, issues et autres contributions qui ne respectent pas ce Code of Conduct, et exclure temporairement ou définitivement les personnes dont le comportement est inapproprié.

## Signalement

Pour signaler un abus : ouvrir une issue privée via les mainteneurs du dépôt, ou écrire à l’adresse indiquée dans [SECURITY.md](SECURITY.md) si le signalement est sensible.

Ce Code of Conduct s’inspire du [Contributor Covenant](https://www.contributor-covenant.org/) v2.1.
